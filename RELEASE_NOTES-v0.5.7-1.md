## 🇷🇺 Русский

### Что нового
- Поддержка Qoder 0.5.7: переведены 25 новых и изменённых строк интерфейса, словарь обновлён до 10 202 ключей.
- Все исправления подверсии v0.5.5-2: выбор языка «Русский» при создании Repo Wiki без ошибки, определение активной копии Qoder после внутреннего обновления (`.qoder-versions`), режим `--detect`.

### Исправления
- Установщик больше не читает версию из базовой папки, оставшейся от старой установки: активная копия берётся из `.qoder-versions\<версия>` по указателю лаунчера Qoder.

### Установка
Полностью закройте Qoder (включая значок в трее), скачайте архив ниже, распакуйте и запустите `QoderRU-Setup-0.5.7.exe`. Папка Qoder определится автоматически, включая копии из `.qoder-versions`.

## 🇬🇧 English

### What's New
- Qoder 0.5.7 support: 25 new and changed interface strings translated, dictionary updated to 10,202 keys.
- All fixes from subrelease v0.5.5-2: error-free Russian language pick on Repo Wiki creation, active Qoder copy resolution after internal updates (`.qoder-versions`), `--detect` mode.

### Bug Fixes
- The installer no longer reads the version from the base folder left over from an old install: the active copy is taken from `.qoder-versions\<version>` via the Qoder launcher pointer.

### Installation
Fully quit Qoder (including the tray icon), download the archive below, unpack it and run `QoderRU-Setup-0.5.7.exe`. The Qoder folder is detected automatically, including `.qoder-versions` copies.
