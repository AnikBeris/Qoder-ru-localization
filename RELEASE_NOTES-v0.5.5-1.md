## 🇷🇺 Русский

### Что нового
- Переведён плагин **«База знаний»**: страница баз знаний (пустое состояние, поиск, фильтры), создание базы знаний и все служебные сообщения.
- Переведена страница **«Вики репозитория»**: hero-блок, вкладки «Все / Сгенерировано / Не сгенерировано», карточка проекта и кнопка «Перейти к генерации».
- Переведена галерея шаблонов агентов, включая четвёртый шаблон «Writing reviewer».
- Переведены названия ролей в форме командного шаблона: менеджер проекта, исследователь, full-stack-инженер, инженер по тестированию, код-ревьюер.
- Переведены настройки плагинов «Индекс рабочей области» и «Безопасность».

### Исправления
- Установщик обновляет контрольные суммы `catalog.v1.json` после правки плагинов, поэтому Qoder больше не показывает «Ресурс представления плагина не найден».
- Добавлены недостающие подписи бокового меню и фильтров.

### Совместимость
- Windows x64.
- **Только Qoder 0.5.5.** После обновления Qoder установите актуальную подверсию русификатора.

### Установка
1. Полностью закройте Qoder (включая трей).
2. Скачайте архив ниже, распакуйте и запустите `QoderRU-Setup-0.5.5.exe`.
3. Нажмите «Установить русский». Откат — кнопкой «Откатить».

## 🇬🇧 English

### What's New
- Translated the **Knowledge Base** plugin: empty state, search, filters, creation flow and service messages.
- Translated the **Repo Wiki** page: hero block, All / Generated / Not generated tabs, project card and the "Go to generate" action.
- Translated the agent template gallery, including the fourth "Writing reviewer" preset.
- Translated team template role names: Project manager, Researcher, Full-stack engineer, Test engineer, Code reviewer.
- Translated the Workspace index and Security plugin settings.

### Bug Fixes
- The installer now refreshes `catalog.v1.json` checksums after patching plugins, so Qoder no longer shows the missing-plugin-view error.
- Added missing sidebar and filter labels.

### Compatibility
- Windows x64.
- **Qoder 0.5.5 only.** Reinstall the matching localization subrelease after updating Qoder.

### Installation
1. Fully quit Qoder, including the tray icon.
2. Download the archive below, unpack it and run `QoderRU-Setup-0.5.5.exe`.
3. Click «Установить русский». Rollback is available via «Откатить».
