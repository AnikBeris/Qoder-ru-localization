## 🇷🇺 Русский

### Что нового
- Полная русская локализация Qoder 0.5.5: около 10 200 строк интерфейса.
- Поддержка новой схемы каталогов Qoder 0.5.5.
- Переведено окно обновления: «Установить Qoder 0.5.5», «Обновить позже», «Установить и перезапустить».
- Переведены состояния чата: «Сборка картины…» (Connecting the dots…), «Направить» (Steer), подсказка «Нажмите и удерживайте мышь для диктовки текста».

### Исправления
- Исправлена пересборка `app.asar` для версий с выравниванием заголовка (0.5.5).
- Установщик строго проверяет версию Qoder и отказывается работать с другой версией.
- Устранены английские подписи в настройках («Security» → «Безопасность»).

### Совместимость
- Windows x64.
- **Только Qoder 0.5.5.** Каждое обновление Qoder заменяет `app.asar` и удаляет локализацию — после обновления установите русификатор для новой версии.

### Установка
1. Полностью закройте Qoder (включая трей).
2. Скачайте архив ниже, распакуйте и запустите `QoderRU-Setup-0.5.5.exe`.
3. Нажмите «Установить русский». Откат — кнопкой «Откатить».

## 🇬🇧 English

### What's New
- Full Russian localization for Qoder 0.5.5: about 10,200 UI strings.
- Support for the new Qoder 0.5.5 catalog layout.
- Translated update dialog: "Install Qoder 0.5.5", "Update later", "Install and restart".
- Translated chat states: "Connecting the dots...", "Steer", and the voice hint "Press and hold the mouse to dictate text".

### Bug Fixes
- Fixed `app.asar` rebuild for versions with header padding (0.5.5).
- The installer now strictly checks the Qoder version and refuses mismatches.
- Removed untranslated settings labels ("Security" → «Безопасность»).

### Compatibility
- Windows x64.
- **Qoder 0.5.5 only.** Every Qoder update replaces `app.asar` and removes the localization; install the matching localization again after updating.

### Installation
1. Fully quit Qoder, including the tray icon.
2. Download the archive below, unpack it and run `QoderRU-Setup-0.5.5.exe`.
3. Click «Установить русский». Rollback is available via «Откатить».
